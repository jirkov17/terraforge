# Terraforge

Редактор карт для моей фэнтези-вселенной: генерация рельефа и «лепка» его кистями
(2D-вид сверху, дальше 3D-просмотр), экспорт карты. Это пет-проект для резюме
(ищу работу разработчиком) и способ подтянуть C++. План по этапам — в `ROADMAP.md`.

## Как со мной работать

- Общайся по-русски. Код, комментарии, имена, коммиты и тексты в UI — на английском.
- Я учу C++: объясняй, почему выбрано решение, и называй возможности языка,
  которые используешь (RAII, move-семантика, `std::span`, ranges, `constexpr` и т. д.).
- Алгоритмы (генерация, эрозия, поиск пути, undo/redo, работа с БД) я пишу сам:
  предложи интерфейс и план, оставь мне `TODO(human)`, потом сделай ревью моего кода.
  Рутину (CMake, подключение библиотек, обвязку UI) можешь делать сам.
- Перед большой задачей сначала план (plan mode), потом код. Один этап `ROADMAP.md` за раз,
  маленькими шагами. После этапа отметь его в `ROADMAP.md`.
- Новые зависимости — только после моего согласия.

## Команды

Windows, генератор Visual Studio CMake выбирает сам. Нужны в PATH: `cmake`, `git`.

```
cmake -S . -B build                                  # первый раз скачивает зависимости (~150 МБ)
cmake --build build --config Release                 # сборка
ctest --test-dir build -C Release --output-on-failure # тесты
build/bin/Release/terraforge.exe                     # запуск
```

- После изменений в `src/core` обязательно собери проект и прогони тесты.
- Окно приложения запускаю и проверяю я сам — после изменений в UI скажи, что посмотреть руками.

## Архитектура

- `src/core/` — данные и алгоритмы на чистом C++20, без raylib и ImGui. Покрыты тестами
  в `tests/` (GoogleTest). Новая логика в core — новый тест.
  - `Heightmap` — сетка высот в [0, 1], хранится по строкам (`index = y * width + x`).
  - `TerrainGenerator` — fBm-шум (FastNoiseLite) + маска острова; детерминирован по seed.
  - `Brush` — кисти Raise / Lower / Smooth / Flatten; скорость не зависит от FPS (`dt`).
  - `MapColorizer` — высоты в цвета: глубина или высота над морем, отмывка рельефа, берег.
- `src/app/` — окно, ввод, рендер и UI (raylib + Dear ImGui через rlImGui).
  - `App` — главный цикл: ввод → обновление → отрисовка. Порядок полей важен:
    `Window` создаётся первым, потому что текстуры живут только при открытом окне.
  - `MapRenderer` — пиксели на CPU → текстура на GPU. `Window`, `ImGuiLayer` — RAII-обёртки.
- Уровень моря — настройка отображения (`ColorizeSettings`), а не часть данных карты.
- Зависимости подключаются через CMake FetchContent в `cmake/Dependencies.cmake`.

## Стиль кода

- C++20, форматирование по `.clang-format` (4 пробела, 100 колонок), namespace `tf`.
- Типы — `PascalCase`, функции и переменные — `camelCase`, поля — `m_name`, константы — `kName`.
- Никаких `new`/`delete`: RAII, `std::vector`, `std::unique_ptr`.
- Явные `static_cast` вместо неявных преобразований: сборка идёт с `/W4` и `-Wconversion`,
  предупреждений быть не должно (в CI на Linux они считаются ошибками).
