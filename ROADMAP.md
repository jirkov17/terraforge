# Роадмап Terraforge

Каждый этап — законченная фича, которую можно показать и о которой можно рассказать
на собеседовании. Делай по одному этапу, коммить часто, после этапа отмечай его здесь.

## ✅ Этап 0. Каркас

- [x] CMake + FetchContent: raylib, Dear ImGui, rlImGui, FastNoiseLite, GoogleTest
- [x] Ядро без графики: `Heightmap`, генерация шумом, кисти, раскраска карты
- [x] 2D-вид с зумом и перемещением, панель настроек, экспорт в PNG
- [x] 23 юнит-теста, CI на GitHub Actions (Windows + Linux)

## Этап 1. Удобный интерфейс и русский язык

- [ ] Шрифт с кириллицей (Noto Sans, OFL) в `assets/fonts/`, копируется рядом с `.exe`
- [ ] Локализация EN / RU: таблица переводов в ядре, проверка полноты при компиляции (`consteval`)
- [ ] Настройки приложения (`terraforge.ini`): выбранный язык сохраняется между запусками
- [ ] Раскладка: меню сверху, панель инструментов с иконками слева, свойства справа,
  строка состояния снизу; генерация — в отдельном окне

**Прокачаешь:** UTF-8 и `char8_t` в C++20, `consteval` / `static_assert`, `std::string_view`,
ID виджетов в immediate-mode UI.

## Этап 2. Миры в SQLite и стартовое меню

- [ ] Файл мира `*.tfworld` — это база SQLite: карта высот (BLOB), настройки, дата изменения
- [ ] Стартовый экран: «Новый мир», «Открыть», список недавних миров
- [ ] Диалог «Новый мир»: название, размер карты, seed, параметры генерации
- [ ] Сохранить / Открыть / Автосохранение
- [ ] Версия схемы (`PRAGMA user_version`) и миграции
- [ ] RAII-обёртка над `sqlite3*`, подготовленные запросы, транзакции
- [ ] Экраны приложения (стартовый ↔ редактор) — машина состояний на `std::variant`

**Прокачаешь:** SQL, проектирование схемы, транзакции, работу с C-API из C++, `std::variant` и `std::visit`.
**Для резюме:** «хранение проектов в SQLite, миграции схемы» — то, что ценят работодатели.

## Этап 3. Форма континента

- [ ] Кисть «суша / море»: грубо нарисовать контур материка, шум добавляет горы, заливы и побережья
- [ ] Заготовки формы для диалога «Новый мир»: континент, архипелаг, два материка с проливом,
  внутреннее море
- [ ] Маска формы хранится в файле мира, генерацию можно повторить с другим seed

**Прокачаешь:** смешивание полей (маска × шум), поле расстояний (distance field), размытие.

## Этап 4. 3D-просмотр

- [ ] Переключение 2D / 3D (клавиша `Tab` или кнопка)
- [ ] Меш из карты высот (`GenMeshHeightmap`) с цветной картой в качестве текстуры
- [ ] Орбитальная камера: вращение, зум, наклон
- [ ] Меш перестраивается после правок кистью, но не чаще нескольких раз в секунду

**Прокачаешь:** 3D-камеры, меши, разницу между данными на CPU и в видеопамяти, RAII для `Model`.

## Этап 5. Отмена и повтор (Undo / Redo)

- [ ] Каждый мазок кисти — команда, которая хранит изменённый прямоугольник «до» и «после»
- [ ] `Ctrl+Z` / `Ctrl+Y`, ограничение истории по памяти
- [ ] Генерация тоже отменяется

**Прокачаешь:** паттерн «Команда», move-семантику, `std::unique_ptr`, выбор между
наследованием и `std::variant`. Undo/redo — частый вопрос на собеседованиях.

## Этап 6. Объекты мира: поселения, метки, подписи

- [ ] Слой объектов с названием и описанием: город, замок, деревня, монастырь, руины, заметка
- [ ] Добавление, перетаскивание, удаление; хранение в SQLite (таблицы, связи)
- [ ] Подписи на карте на русском: шрифт из этапа 1 через `LoadFontEx` + нужные кодпоинты, UTF-8

**Прокачаешь:** моделирование данных, связи таблиц, работу с текстом и Unicode.

## Этап 7. Нейросети: лор и названия

- [ ] Кнопка «Описать место»: собираем контекст (биом, высота, соседние объекты)
  и отправляем в языковую модель — облачный API или локальную модель (llama.cpp / Ollama)
- [ ] Модель возвращает JSON: название, история, народы; сохраняем в SQLite (кэш)
- [ ] Запрос идёт в фоне, интерфейс не зависает; ошибки сети показываются в UI
- [ ] Ключ API — только из переменной окружения, никогда в коде и в git
- [ ] Бонус: «опиши мир словами» → модель подбирает параметры генерации

**Прокачаешь:** HTTP-клиент, JSON (nlohmann/json), асинхронность (`std::jthread`, `std::future`),
обработку ошибок, безопасность секретов.
**Для резюме:** «интеграция LLM в десктопное приложение на C++».

## Этап 8. Производительность

- [ ] Замерь время кадра профилировщиком Visual Studio (Debug и Release)
- [ ] Перекрашивай только изменённую область карты (dirty rectangle), а не всю текстуру
- [ ] Генерация в несколько потоков, сравни скорость
- [ ] Карты 1024 и 2048 без подтормаживаний

**Прокачаешь:** профилирование, кэш-дружелюбный код, многопоточность.
**Для резюме:** цифры «было → стало» (например, перерисовка кистью в 20 раз быстрее).

## Этап 9. Реки, озёра и эрозия

- [ ] Гидравлическая эрозия (симуляция капель) — рельеф становится реалистичным
- [ ] Направление стока и накопление воды → реки; заполнение впадин → озёра (priority-flood)

**Прокачаешь:** алгоритмы на сетках, очередь с приоритетом, численную симуляцию.

## Этап 10. Климат, биомы и королевства

- [ ] Температура (широта и высота) и влажность (удалённость от моря) → биом по диаграмме Уиттекера
- [ ] Королевства: рост регионов от столиц по стоимости рельефа (Дейкстра); цвет и простой герб
- [ ] Дороги между поселениями (A*) с учётом склонов и рек
- [ ] Калькулятор пути: «сколько дней верхом из А в Б» по дорогам и бездорожью

**Прокачаешь:** графовые алгоритмы, проектирование слоёв данных.

## Этап 11. Витрина

- [ ] README с GIF-демо, бейдж CI, релиз на GitHub (zip с `.exe`)
- [ ] clang-tidy и санитайзеры (ASan / UBSan) в CI
  (UBSan ругается на переполнение `int` в хешах FastNoiseLite — это сторонний код, его можно исключить)
- [ ] Покрытие тестами ключевого кода

## Бонусы для прокачки C++

- Свой шум Перлина / Simplex вместо FastNoiseLite — и сравнение скорости
- Раскраска карты в GLSL-шейдере на видеокарте
- Сборка под Web через Emscripten — живая демо-ссылка в резюме
- Стиль «старый пергамент»: сепия, штриховка гор, роза ветров, шкала в лигах
- Фэнтези-слой: магические зоны, лей-линии, подземелья, туман неизведанных земель
