# Разложить служебные файлы

Эти два файла нельзя было записать в служебные папки удалённо, поэтому они лежат здесь.
Перенеси их и удали папку `setup`:

| Файл | Куда | Зачем |
|---|---|---|
| `ci.yml` | `.github/workflows/ci.yml` | GitHub Actions собирает проект и гоняет тесты на каждый push |
| `settings.local.json` | `.claude/settings.local.json` | Claude Code работает в стиле Learning: объясняет решения и оставляет тебе куски кода |

Проще всего попросить Claude Code: «Перенеси файлы из папки setup туда, куда сказано в setup/README.md, и удали setup».
